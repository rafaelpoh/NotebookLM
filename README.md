# Projeto NotebookLM: Estudos de React

Eu costumo criar um projeto no NotebookLM sempre que vou iniciar estudos de alguma tecnologia nova, projeto ou assunto que eu queira pesquisar a fundo. 

Neste caso, como estou iniciando meus estudos sobre **React**, decidi usar a ferramenta para organizar meu aprendizado e criar um material de exemplo para apresentar como projeto do bootcamp da DIO.

## Fontes Utilizadas

Para alimentar a base de conhecimento do NotebookLM, utilizei os seguintes materiais:

- **Documentação Oficial:**
  - [React Docs (pt-BR)](https://pt-br.react.dev) - A documentação oficial não poderia faltar como fonte essencial de pesquisa.

- **Vídeos do YouTube:**
  Alguns vídeos que encontrei para alimentar a fonte de conhecimento:
  - https://www.youtube.com/watch?v=ttfRRdONvxM
  - https://www.youtube.com/watch?v=_gHr2Pe5LCY
  - https://www.youtube.com/watch?v=NhUr8cwDiiM

Por fim, pedi para o NotebookLM buscar outras fontes de conhecimento usando o recurso de *"deep research"* para complementar o estudo.

## Prompt Utilizado

Para iniciar a geração do conteúdo, o prompt fornecido ao NotebookLM foi:

> "Estou querendo começar meus estudos com React, explique tudo sobre o assunto."
